# Optional voice reference sample

The Chatterbox service reads an optional WAV file from this folder at runtime:

`voice.wav`

This file is intentionally not included in Git. Only place a clean voice recording here if you own it or have permission to clone it. Do not commit private or copyrighted recordings. Without `voice.wav`, Chatterbox uses its default speaker. The source ZIP for Hady Raie Voice Act contains no reference recording, so export/download a sample separately from that application if you want to test similar timbre.
